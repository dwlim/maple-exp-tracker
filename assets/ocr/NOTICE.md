# Local OCR assets

Tesseract.js 7.0.0 and tesseract.js-core 7.0.0, Apache-2.0. Sources: https://github.com/naptha/tesseract.js and https://github.com/naptha/tesseract.js-core . English data: https://cdn.jsdelivr.net/npm/@tesseract.js-data/eng@1.0.0/4.0.0_best_int/eng.traineddata.gz , from the Apache-2.0 Tesseract language data project.

Uncompressed model SHA-256: 5dc5d8d640a212c9d6184921ba103b186f50e0fed9ee716c53e6b312b400d747 .

The runtime and model are served by this site. Recognition runs in a local Web Worker. No image or reading is uploaded. The runtime is loaded only when the lightweight matcher cannot read a capture.
